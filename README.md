# mi-primer-proyecto

Mi primer proyecto para aprender desarrollo web, hecho con [Next.js](https://nextjs.org).

## Cómo correrlo

```bash
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Estructura

- `app/page.tsx` — la página de inicio.
- `app/layout.tsx` — layout raíz compartido por todas las páginas (fuentes, metadata, HTML/body).
- `app/globals.css` — estilos globales y configuración de Tailwind.
- `public/` — archivos estáticos (imágenes, íconos).
